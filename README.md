# PySint

# 🇬🇧 ENGLISH LANGUAGE

PySint is a simple OSINT search tool written in Python.

## Features

- Google, Bing, DuckDuckGo
- Web, News, Images, Video search
- Exact search
- SafeSearch
- Incognito mode
- Language and region filters
- Source filters
- Username, E-mail, Phone, Domain, IP, URL and Name search

## Installation

```bash
pip install selenium webdriver-manager

PySint — это простой инструмент для OSINT-поиска, написанный на Python.

## Возможности

- Поиск в Google, Bing, DuckDuckGo
- Поиск в интернете, новостях, изображениях, видео

- Безопасный поиск
- Режим инкогнито
- Фильтры по языку и региону
- Фильтры по источнику
- Поиск по имени пользователя, электронной почте, телефону, домену, IP, URL и имени
