# PySint

# 🇬🇧 ENGLISH LANGUAGE

PySint is a simple OSINT search tool written in Python.

## Features

- Google, Bing, DuckDuckGo
- Web, News, Images, Video search
- Exact search
- SafeSearch
- Incognito mode
- Language and region filters
- Source filters
- Username, E-mail, Phone, Domain, IP, URL and Name search
